# وضعیت پیشرفت پروژه (Progress Tracker)

## فاز اول: حداقل محصول پذیرفتنی (MVP)

- [x] **مرحله A: زیرساخت و دسترسی**
  - [x] راه‌اندازی و تست پایگاه داده (SQLite برای تست، PostgreSQL برای محیط واقعی)
  - [x] ساختار کاربران، نقش‌ها (مدیر، حسابدار، فروشنده، انباردار) و Middleware فعال بودن
  - [x] تنظیمات فروشگاه، شعبه پیش‌فرض و انبار پیش‌فرض
  - [x] پوسته کاربری فارسی (RTL، استایل Tailwind و منوی دسترسی)
  - [x] تست‌های خودکار مرحله A (۲۷ تست پاس شده)

- [x] **مرحله B: اطلاعات پایه و کاتالوگ محصولات**
  - [x] طرف‌های حساب (اشخاص، نقش‌های چندگانه مشتری/تأمین‌کننده، سقف اعتبار)
  - [x] برندها و دسته‌بندی‌ها
  - [x] محصولات (کالای تعدادی، کالای سریالی/گوشی، خدمات)
  - [x] تنوع محصول (SKU، بارکد، رنگ، حافظه، قیمت‌ها)
  - [x] دستگاه‌های فیزیکی و شناسه‌ها (IMEI اول و دوم با قید یکتایی سراسری)
  - [x] فرم ارزیابی سلامت باتری و رجیستری
  - [x] تست‌های پذیرش شماره ۴ و ۵ (اعتبارسنجی IMEI، صفرهای اول، یکتایی)

- [x] **مرحله C: هسته مالی، انبار و خرید**
  - [x] سرفصل حساب‌های دفتر کل و حساب‌های مالی (صندوق، بانک، کارت‌خوان)
  - [x] موتور ثبت دوبل متوازن و اتمیک
  - [x] موجودی انبار، گردش موجودی و محاسبه میانگین موزون متحرک
  - [x] فاکتور خرید با سرشکن هزینه‌های جانبی خرید (Landed Costs)
  - [x] دریافت و پرداخت و تسویه بدهی تأمین‌کننده

- [x] **مرحله D: فروش، صندوق (POS) و تسویه**
  - [x] فاکتور فروش ترکیبی (کالا، گوشی با IMEI الزامی، خدمات)
  - [x] توزیع دقیق تخفیف کلی بین اقلام و قفل موجودی هم‌زمان
  - [x] کنترل حداقل قیمت و سقف اعتبار مشتری
  - [x] تسویه چندوجهی (نقدی، کارت‌خوان، انتقال بانکی، نسیه/اعتباری)
  - [x] قالب‌های چاپ استاندارد A4 و فیش پرینتر ۸۰ میلی‌متری

- [x] **مرحله E: خدمات، مرجوعی، هزینه‌ها و تعدیل**
  - [x] فرم‌ساز نسخه‌دار خدمات و سفارشات خدمات با گردش وضعیت (`queued` -> `in_progress` -> `ready` -> `delivered`) و لغو مستند
  - [x] مرجوعی فروش (با انتقال دستگاه‌های برگشتی به وضعیت قرنطینه فنی و برگشت بهای اسنپ‌شات اولیه)
  - [x] ثبت هزینه‌های جاری با ثبت دوبل خودکار (بدهکار ۶۰۱، بستانکار ۱۰۱)
  - [x] ثبت انتقال داخلی وجوه بین صندوق، بانک و کارت‌خوان بدون تغییر سود و زیان
  - [x] تعدیل فیزیکی انبارگردانی (کسری و اضافات با ثبت حسابداری ۶۰۲ و تأیید اختصاصی مدیر)
  - [x] تست‌های خودکار مرحله E با ۶ آزمون جامع و ۵۳ سنجش

- [x] **مرحله F: گزارش‌های مدیریتی، امنیت و تحویل نهایی**
  - [x] گزارش‌های تحلیلی سود ناخالص کالایی مجزا از حاشیه برآوردی خدمات
  - [x] تحلیل عملکرد و رتبه‌بندی برندها بر اساس تعداد، فروش و سود خالص ریالی
  - [x] تحلیل و طبقه‌بندی مشتریان (فعال، غیرفعال بیش از ۹۰ روز، ثبت‌شده بدون خرید و سودده‌ترین مشتریان)
  - [x] ارزش‌گذاری موجودی انبار، تطبیق با حساب ۱۰۳ دفتر کل و شناسایی کالاهای راکد
  - [x] تراز آزمایشی دفاتر کل و تأیید توازن دقیق بدهکار و بستانکار
  - [x] خروجی فایل امن CSV با ایمن‌سازی ضد Formula Injection (کاراکترهای `=, +, -, @`) و هدر BOM
  - [x] تفکیک قطعی دسترسی فروشنده از ارقام بهای تمام‌شده و سود در UI، JSON، CSV و چاپ
  - [x] پیشخوان با KPIهای بلادرنگ دیتابیس (فروش امروز، خدمات باز، دستگاه‌های انبار و مانده نقدینگی)
  - [x] پوشش کامل آزمون‌های خودکار: ۵۹ تست موفق (۳۰۲ سنجش) بدون خطا
